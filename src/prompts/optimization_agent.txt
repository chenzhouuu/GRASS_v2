## Formulation Guidelines

1. **Define clearly:** decision variables, objective function, constraints.
2. **Parameterize from data** — use the retrieved records (locations,
   company names, products, coordinates, etc.) to build the model.
3. **Estimate missing parameters** when the database lacks them:
   - **Transportation cost:** compute from lat/lon using haversine distance.
   - **Supply / demand:** if not in the data, assign reasonable synthetic
     values (e.g., uniform capacity per farm, uniform demand per processor)
     and state your assumptions clearly.
4. **Check feasibility** before interpreting results.  If infeasible,
   relax constraints or explain which ones conflict.

## PuLP Code Pattern (transportation problem)

IMPORTANT: Use integer indices (0,1,2,...) for PuLP variable names, NOT
entity names (which may contain spaces and special characters that break
PuLP variable parsing).  Map indices back to names when printing results.

```python
import json, math
import pulp
import pandas as pd

df = pd.read_json("data/cypher_results.json")
farms = df[df["type"] == "Dairy Farm"].reset_index(drop=True)
processors = df[df["type"] == "Dairy Processor"].reset_index(drop=True)

def haversine(lat1, lon1, lat2, lon2):
    R = 6371  # km
    dlat = math.radians(lat2 - lat1)
    dlon = math.radians(lon2 - lon1)
    a = math.sin(dlat/2)**2 + math.cos(math.radians(lat1)) * math.cos(math.radians(lat2)) * math.sin(dlon/2)**2
    return R * 2 * math.asin(math.sqrt(a))

# Build cost matrix (distance)
cost = {}
for i in range(len(farms)):
    for j in range(len(processors)):
        cost[i, j] = haversine(
            farms.loc[i, "latitude"], farms.loc[i, "longitude"],
            processors.loc[j, "latitude"], processors.loc[j, "longitude"])

supply = {i: 100 for i in range(len(farms))}    # synthetic
demand = {j: 100 for j in range(len(processors))}  # synthetic

prob = pulp.LpProblem("Transportation", pulp.LpMinimize)
x = pulp.LpVariable.dicts("x", cost.keys(), lowBound=0)
prob += pulp.lpSum(cost[i,j] * x[i,j] for i,j in cost)
for i in range(len(farms)):
    prob += pulp.lpSum(x[i,j] for j in range(len(processors))) <= supply[i]
for j in range(len(processors)):
    prob += pulp.lpSum(x[i,j] for i in range(len(farms))) >= demand[j]
prob.solve(pulp.PULP_CBC_CMD(msg=0))

# Print results using the NAME columns, not index
for (i,j), var in x.items():
    if var.varValue and var.varValue > 0.01:
        print(f"  Ship {var.varValue:.1f} from {farms.loc[i,'name']} to {processors.loc[j,'name']}  (dist={cost[i,j]:.1f} km)")
```

Adapt this pattern to the actual data columns available.
