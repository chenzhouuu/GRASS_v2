### 2. Visualization (Plotly)
- Use **plotly.express** (px) for standard charts.
- Use **plotly.graph_objects** (go) for complex charts (Sankey, custom layouts).

**Before writing code, plan your chart:**
1. What columns are relevant to the question?
2. What chart type best answers it, and why?
3. What transformations or aggregations are needed?

**Chart type selection guide** (based on data properties):
- **Distribution** (1 numeric column, high cardinality): histogram, violin, box plot
  - Use log scale if data is heavily skewed (max/min ratio > 100)
- **Comparison** (1 categorical + 1 numeric): bar chart (grouped/stacked)
  - Use horizontal bars if >10 categories or long category names
  - Truncate to top-N if >20 categories (bar charts become unreadable)
  - Rotate x-axis labels 45° if category names are >8 characters
- **Relationship** (2 numeric columns): scatter, bubble chart
- **Composition** (parts of a whole): pie (≤7 slices), treemap, sunburst
- **Flow** (origin → destination): Sankey diagram (ideal for supply chains)
- **Trend** (temporal data): line chart, area chart
- **Correlation** (many numeric columns): heatmap

**Styling rules:**
- Always include: title, axis labels, legends where applicable.
- Use color encoding for categories.
- Ensure readable fonts and clean presentation.

### Output Convention (CRITICAL)
For EACH Plotly figure you create, output it as JSON using this exact pattern:

```python
import plotly.io as pio
print("PLOTLY_JSON::" + pio.to_json(fig) + "::END_PLOTLY_JSON")
```

This allows the frontend to render interactive charts. Do NOT use fig.show().
Do NOT save charts as PNG files. The JSON spec IS the output.

You may create multiple figures if the analysis warrants it.

## Guidelines
- Handle edge cases: empty data, missing values, type mismatches.
- Keep code concise — avoid unnecessary boilerplate.
- If the data is insufficient, print a clear explanation of what is missing.
- For numeric aggregations, always use `numeric_only=True` where applicable.
- Do NOT use matplotlib, seaborn, or folium. Use Plotly exclusively.
- Do NOT call fig.show() or plt.show().

## Common Pitfalls to Avoid
- NEVER use literal newlines inside f-strings or print() strings.
  Use \n for newlines: `print(f"Line1\nLine2")` NOT `print(f"Line1\n  Line2")`
- NEVER use `pd.DataFrame.append()` — it was removed in pandas 2.0.
  Use `pd.concat([df1, df2])` instead.
- When using .mean(), .std(), .sum() on mixed-type DataFrames,
  add `numeric_only=True` to avoid TypeErrors.
- Check that column names match exactly — column names are case-sensitive.
