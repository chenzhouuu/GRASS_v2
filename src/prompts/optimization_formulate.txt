## CRITICAL: avoid degenerate min-cost models (must move product)
A minimize-cost transportation/allocation problem with ONLY upper-bound (<=)
constraints is degenerate: shipping nothing costs $0 and is "optimal". This is
WRONG for supply-chain allocation — the product must actually move. ALWAYS add a
flow-forcing constraint:
- If total supply <= total capacity: require each supply node to be FULLY
  allocated — for each i: sum_j x[i,j] == supply[i].
- Otherwise (supply exceeds capacity): require each demand/intake node to be met —
  for each j: sum_i x[i,j] >= demand[j], and maximize allocated volume or report
  unmet supply.
Do NOT default to all-<= "and report unmet supply" — that yields a $0 no-op plan.
Every allocation/transportation formulation MUST contain at least one == or >=
constraint that forces flow.
